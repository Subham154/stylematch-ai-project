# StyleMatch AI 👕✨

An AI-powered clothing similarity finder built with Python, Streamlit, and CLIP embeddings.

Upload a clothing image and the application returns the top 5 most visually similar items from a dataset of 600+ fashion product images.

## Features

- Upload a clothing image
- Find visually similar products
- Uses CLIP embeddings for image comparison
- Displays the top 5 similar items

## Technologies Used

- Python
- Streamlit
- OpenAI CLIP
- PyTorch
- scikit-learn
- Pillow

## How to Run

```bash
git clone https://github.com/Subham154/stylematch-ai-project.git
cd stylematch-ai-project
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
